## 2. Five findings most likely to change the next round's priorities

1. **The N2 kill of F1 is narrower than the handoff will say.** The generator that reproduces +0.04 residual has 1,750 types, h2 1.79, repeats 1.3 % (results_n2.txt) and was not scored on NMI, page MI, labels, M5 anatomy or the v1 board. Before "F1 dead" propagates into PREREG v2, rerun N2 p=0.04 with the lexicon held at 7k types and score that one stream on the K1 bench. If it also hits NMI 0.27/0.33 (it is section-seeded, so it probably does), the content case has nothing left but line edges (item 3, 13). Cost: low.
2. **The type-budget argument (K_RESULTS point 3) is already refuted on disk.** results_k4.txt (18:30) reaches 5.4–5.6k types with h2 2.23–2.27, crossMI ≥ +0.21 and residual +0.04–0.05; it misses only hand-2 NMI and line edges. K_RESULTS.md's "No tested mechanism does that" and PREREG-v2 M19 ("every producer needs 15–25k types") are stale by one round. Also, M19 kills generators (1.6–1.9k types) harder than it kills codes, which no doc says. Cost: none (rewrite), medium (K4 + sectioned hand-2 plaintext).
3. **Line edges are the only remaining discriminator and the project has zero real-manuscript line data.** All L controls are pseudo-lines, so "no language control reaches the edge bands" is true by construction, and every producer gets the same Voynich-fitted layer (M5), so the bands no longer discriminate producers either. One 15th-century Latin manuscript transcription with line breaks, scored on jsd_first_fg/p/m and m5 anatomy, is the highest-value single control the project can add. Cost: medium.
4. **The v1 board is built from the target and does not hold inside it.** Bands are "derived from filed gaps" around Voynich's values; Currier A alone FAILS (m_final ×6.21 < 8, results_m4). L1's "Voynich passes 200/200 splits" is therefore tautological, and the G1 circular "miss" of JSDf by 0.0006 is inside Voynich's own sampling width (0.148–0.211). PREREG v2 should set bands from within-Voynich variability (A/B, hands, 41-page splits) and bootstrap *entrants'* held-out values, not the target's. Cost: low.
5. **The "G favoured" verdict of m4 rests on G controls that are Voynich fitted** (c2 seeded from Voynich types, T–S seeded with f103v.P.9, schwartz_reuse, markov1 on Voynich glyphs) scoring "in" on h2/redup/position-entropy/sd, while the L family is "out" on three edge metrics it cannot score by construction and on two metrics undefined for its abjad members (`inf`). One non-Voynich-fitted G control (Rugg over a Latin syllable table; T–S seeded with Latin) and N/A-aware out counts would likely erase the margin of 2. Cost: medium.

## 3. Things the project does NOT know that it talks as if it does

- **What real scribes do at line edges.** No control has real lines; no number for line-initial/final glyph preference in any 15th-century manuscript exists in the folder. "Anomaly outside every family" (PLAN §6 point 8) means "outside every pseudo-line".
- **Whether the edge coupling is a property of Voynich or of the table it was handed.** F3/G1/H1/K1–K4/N1/N2 all carry Voynich's own R. No producer has been given a non-Voynich edge table and scored on held-out Voynich.
- **Whether generation is favoured or just better imitated.** Every G control except rugg_grille is seeded, fitted or poured from Voynich. The one unfitted generator (markov1) fails sd_len and JSD.
- **Whether the two-family framing is exhaustive.** A copied-without-understanding text, a formulaic liturgy, a sincere conlang and a non-linguistic notation are each compatible with the constraint set and none has a control.
- **Whether "no list order" in labels means "not names".** m6 tested glyph similarity of neighbours, which names fail too. The star/zodiac cribs on disk are unused.
- **The power of its negatives.** Only F4 got a power check (i1). a3/d6 (p=0.09–0.11, 40 pages), c1 hand 2 (7 blocks), m1 (P=0.068), m6 (25 tests) are reported as leaning meaningless; none has an injected-effect detection curve.
- **Whether h2 ≈ 2.1 is a property of the text or of EVA.** m7: 2.13 (EVA) → 2.40 (glyph+) → 2.54 (v101). The band that kills every generator is set on one alphabet, and producers are scored in EVA strings they were built from.
- **Where the word boundaries are.** '?' tokens dropped (212 in ZL3b), uncertain spaces treated as breaks (joining them moves coupling −0.03), word boxes disagree with ink on 26 % of zero-gap sites (o1). E1 tested joins only, never ink-driven splits.
