# Voynich Reconstruction Atlas

Compare two transcriptions of Yale's Beinecke MS 408, reconstruct the folded sheets, or rerun the fragment puzzles.

**[Start reading · One label, two readings](START-READING.md)**

Inspect a handwritten label on folio 75v, choose where you would place a space, and compare both editions. The example includes an original Yale image detail and a reconstruction puzzle that assigned the same folio incorrectly.

- [Browse the 707 spacing disagreements](spacing-differences.csv) or [inspect the inventory of all matched passages](compare-readings.csv).
- [Open the photograph inventory](photograph-coverage.csv).
- [Fold the first gathering](https://github.com/thisisntjon/voynich/raw/refs/heads/reconstruction-atlas-v1/fold-quire-1.pdf) with its printable sheets.
- [Rerun the experiments](https://github.com/thisisntjon/voynich/raw/refs/heads/reconstruction-atlas-v1/replication-v1.zip) with the inputs, code and reference predictions.

Courtesy of the Yale University Library, Beinecke Rare Book and Manuscript Library, MS 408. See [sources and terms](CREDITS.txt) and [edition citation](CITATION.cff). [Report a correction](https://github.com/thisisntjon/voynich/issues) with the folio and locus.
