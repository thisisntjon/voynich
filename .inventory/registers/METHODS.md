# METHODS register — Voynich project (.)

Stamped 2026-10-17 18:32 PDT (clock read with `date`). Built read-only from source; every
"where implemented" pointer was opened. A pointer of the form `file:function` means the function
body was read. "Test" names the case in `tests/test_score.py` (18 tests) or
`tests/test_voynich.py` (5 tests); "none" means no test pins the value. Numeric values quoted
here are the filed ones named in the pointer; they were not recomputed.

Shared conventions (apply unless a row says otherwise)
- Corpus: `data/ZL3b-n.txt` (ZL IVTFF, EVA) parsed by `vparse.load()`; `vparse.clean()` takes
  `[a:b]` -> a, drops `{}` and `'`, `@nnn;` -> `?`, `<->` and `,` (uncertain space) -> word break
  (unless `strict_spaces`), every other `<...>` tag removed. Running text = units whose locus
  type starts with `P` (`vparse.paragraph_text`). Tokens containing `?` are dropped
  (`corpora.voynich`, `corpora.voynich_lines`, `drop_unclear=True`); empty lines dropped.
  Result: 207 pages, 4130 lines, 34,857 tokens, 7,025 types (results_m0 header; a1 counts
  25,000 cap -> 5,417 types).
- Alphabet: "EVA" = the raw ASCII characters of the token (25-26 symbols incl. space);
  "glyph" = `corpora.GLYPHS` (cth ckh cph cfh ch sh collapsed to one private-use char each);
  "glyph+" = `corpora.GLYPHS_PLUS` (also iiin iin in iir ir ee). `corpora.to_glyphs` replaces
  longest-first.
- Space symbol: a1/score.py `char_entropies` uses `" ".join(words) + " "` (space is a symbol,
  trailing space); b3/b4 `h2()` uses `"_".join(words)` (no trailing separator). These two h2s
  differ in the 3rd decimal on the same tokens (2.126 vs 2.126 at 25k; see h2 row).
- Line = one IVTFF locus record (one `<fNN.n,@Pn>` line). "Mid-line" = words 2..n-1 of lines
  with >= 3 words (a2 convention); lines with < 3 words are skipped by a2/b4/score.py line metrics.
- Seed convention: 20261017 for anything new (PREREG), but each original script pins its own
  (a2 null seeds 0..n-1, a4/a4b `Random(0)`, b3 `Random(7)`, b5 `default_rng(0)` + NMF
  `random_state=0`, c3 `Random(0)`, d1 seed 7, d2 seed 42, d5 `Random(42)`, d6 part b 12345,
  f1 shuffle seed 3, f3 cipher seed 1/2).
- Controls (`corpora.control`): Gutenberg text, lowercased, accents stripped, tokens = `[a-zß]+`,
  front 5 % of tokens skipped; `corpora.CONTROLS` = latin_caesar, latin_augustine,
  italian_dante, german_faust, german_kafka, english_alice. Prose "pseudo-lines" = 9 tokens
  (c3/score.py/f1), 8 tokens x 20 lines/page (run_new, m3, m4), 50 EVA chars (c4 wrap, f2, f4).
